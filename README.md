# Secure Commerce Security Lab

Spring Boot 기반 웹 애플리케이션을 직접 구축하고,
웹 애플리케이션의 취약점을 분석하여 공격 재현,
보안조치 및 재검증까지 수행하는 기술보안 포트폴리오입니다.

추후 SAST, SCA, DAST, Container Scan 등의
DevSecOps 보안 자동화와 AWS 클라우드 보안 환경까지 확장할 예정입니다.

## Project Goals

- Spring Boot 기반 웹 서비스 구축
- 웹 애플리케이션 취약점 구현 및 분석
- 실제 공격 시나리오 재현
- 취약점 원인 분석 및 보안조치
- 수정 전/후 보안성 비교
- CI/CD 보안 자동화
- AWS 클라우드 보안성 검토

## Security Topics

- SQL Injection
- XSS
- IDOR
- Broken Access Control
- JWT Security
- File Upload Security
